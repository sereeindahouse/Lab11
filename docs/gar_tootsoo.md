# Value Iteration — гар тооцоо (XIII долоо хоног)

Орчин: 1×3 коридор `S . G`, γ = 0.95, шагнал: G-д орох +50, бусад алхам −1, V(G)=0.
Нүд: S=(0,0), M=(1,0), G=(2,0). Коридор нэг мөртэй тул дээш/доош хөдөлгөөн → хана → байрандаа үлдэнэ.

## p = 1 (тодорхой)

| k | V_k(S) | V_k(M) | max\|ΔV\| | Тайлбар |
|---|---|---|---|---|
| 0 | 0 | 0 | – | эхлэл |
| 1 | −1 + 0.95·0 = **−1** | 50 + 0.95·0 = **50** | 50 | M→G нэг алхам |
| 2 | −1 + 0.95·50 = **46.5** | **50** | 47.5 | S мэдээг M-ээс "сонссон" |
| 3 | 46.5 | 50 | **0** < θ | нийлсэн |

## p = 0.8 (магадлалт)

M-ээс R: 0.8 → G (+50), 0.2 → байрандаа (−1 + 0.95·V(M)).
S-ээс R: 0.8 → M (−1 + 0.95·V(M)), 0.2 → байрандаа (−1 + 0.95·V(S)).

| k | V_k(S) | V_k(M) | max\|ΔV\| |
|---|---|---|---|
| 1 | 0.8(−1) + 0.2(−1) = **−1** | 0.8·50 + 0.2(−1) = **39.8** | 39.8 |
| 2 | 0.8(−1+0.95·39.8) + 0.2(−1+0.95·(−1)) = **29.058** | 40 + 0.2(−1+0.95·39.8) = **47.362** | 30.058 |
| 3 | 0.8(43.9939) + 0.2(26.6051) = **40.5161** | 40 + 0.2(43.9939) = **48.7988** | 11.458 |
| … | … | … | … |
| ∞ | **294380/6561 = 44.8682** | **3980/81 = 49.1358** | → 0 |

Хязгаар утгыг тэгшитгэлээс шууд бодно:
V(M) = 40 + 0.2(−1 + 0.95·V(M)) ⇒ 0.81·V(M) = 39.8 ⇒ V(M) = 49.1358.
V(S) = 0.8(−1 + 0.95·49.1358) − 0.2 + 0.19·V(S) ⇒ V(S) = 44.8682.
